# public/images — product photography

Drop product images here using the **exact filenames** referenced in
`data/products.ts`:

| File | Used for |
|---|---|
| `fallen-angel-hoodie.jpg` | The Fallen Angel Hoodie |
| `signature-drop-tee.jpg` | Signature Drop Tee |
| `real-legacy-tee.jpg` | Purpose Is The Real Legacy Tee |

Guidelines:
- Portrait orientation, ideally **1200 × 1500 px**
- JPG under ~400 KB (use Squoosh or TinyPNG)
- Name the file exactly as listed (lowercase, dashes)

If a file is missing, the product card automatically shows a branded
placeholder — the page never breaks.
